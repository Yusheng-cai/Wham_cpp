Wham_cpp Documentation

C++ weighted histogram analysis tools for reconstructing free-energy surfaces from biased molecular simulation data.

README Input format WHAM methods Build and test

Quick Start

Build

Compile the executable

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

The main executable is written to build/bin/Wham.

Test

Run validation

ctest --test-dir build --output-on-failure

The registered suite covers UWHAM validation, utility tests, and input generation.

Input

Generate an input file

python3 tools/generate_wham_input.py \
  examples/input_specs/uwham_1d.json -o input.dat

The generator writes the native timeseries, bias, and wham blocks.

WHAM Workflow

time-series samples + bias definitions
        |
        v
evaluate samples or bins under every bias potential
        |
        v
solve WHAM normalization constants f_k
        |
        v
compute unbiased probabilities and free energies
        |
        v
write requested outputs

Methods

UWHAM

Unbinned WHAM uses raw time-series samples directly. The current implementation solves for window normalization constants with L-BFGS, adaptive updates, or both in sequence.

BWHAM

Binned WHAM first maps samples onto configured bins, then solves the binned WHAM equations from bin counts and reduced bias energies.

Reweighting

Reweighting applies an additional target potential after WHAM weights are known, allowing observables to be estimated in a modified ensemble.

Core Equations

Let N_k be the number of samples in window k, B_{k,i} = beta U_k(x_i) be the reduced bias energy, and f_k be the reduced free-energy normalization constant.

UWHAM Objective

A(f) = - sum_k N_k f_k
       + sum_i log[ sum_k (N_k / N_tot) exp(f_k - B_{k,i}) ]

Sample Log Weight

ln w_i = -log[ sum_k N_k exp(f_k - B_{k,i}) ]

Adaptive Candidates

f_k^SC = -log[ sum_i exp(ln w_i - B_{k,i}) ]

(H^T H) delta = H^T grad
f^NR = f - delta

The adaptive solver evaluates both the self-consistent and Newton-Raphson candidates and keeps the one with the smaller gradient norm.

Native Input Shape

timeseries = {
    path = US_0.000.dat
    columns = [ 2 ]
    skipfrombeginning = -1000
}

bias = {
    dimension = 1
    xstar = [ 0.0 ]
    kappa = [ 1000 ]
    temperature = 300
}

wham = {
    name = w
    type = Uwham
    outputs = [ pji normalization ]
    outputFile = [ pji.out norm.out ]
}
